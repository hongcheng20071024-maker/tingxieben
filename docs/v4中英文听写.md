# 听写本 v4：听英文写中文意思

第四版在原来的键盘听写中增加「英文发音 → 写中文意思」。英文拼写听写、中文播报后拼英文、第三版的错词重写、第二版的纸笔草稿纸都继续保留。

## 使用

1. 在主界面勾选词库分组，选择「键盘听写」。
2. 将「朗读内容」设为「英文发音 → 写中文意思」。
3. 点击「开始听写」，播放英文单词，在输入框写出一种完整中文意思，按「检查意思」或 Enter。
4. 每次检查后显示词库的参考释义，可重听英文发音。答错或主动查看答案计入本轮错词，可在结束后「只练错词」。

例如：`bank 银行；河岸`，回答「银行」或「河岸」任意一个即可。`bright 明亮的、聪明的`，回答「聪明」也会接受。

纸笔听写也支持这个朗读选项：播放英文，手写中文意思，最后对照全部释义自行核对。iPad 草稿纸保留，不自动识别笔迹或批改手写答案。

## 多义词判分

判分使用词库中已录入的释义，不调用外部语义服务。多种释义可用分号、逗号、顿号、斜杠、竖线或换行分隔。批量录入词表仍为每行一个单词，建议在同一行用分号区分释义。

常见的 `n.`、`v.`、`vt.`、`vi.`、`adj.`、`adv.` 和释义编号会整理掉；统一全角半角，忽略空格和外围标点。形容词、副词末尾的「的」「地」可省略，名词「目的」「土地」等仍需完整回答。括号中的用法备注不独立算作答案；显式标记「又作」「也作」「即：」「或：」的同义释义可作为答案。`（河）岸` 可以回答「岸」或「河岸」，不能只回答「河」。

紧挨着的圈号释义 `①银行②河岸`、中文编号 `一、非凡的；二、特别的` 和组合词性 `n. & v.`、`n.+v.`、`adj. & adv.` 也会整理；编号本身不算答案。短中文释义之间的冒号可分隔多义，例如 `环境:境遇` 接受「环境」或「境遇」；`例句：`、`释义：` 等说明标签不作为同义答案。

需要一个完整释义匹配，不接受片段或随意包含匹配，例如「益处」不能只答「益」，「需要」不能答「不需要」。如果一次回答了多个释义，每个都必须正确，不能通过混入错误猜测得分。没有录入的同义表达，请在分组中补充为另一种释义，例如 `益处；好处`。

选择的词库含空白释义、仅词性或没有中文的释义时，页面列出需要补全的单词并阻止开始。不会默默跳过这些词。

「答错后再写一遍」仅作用于英文拼写的两种键盘练习；中文意思模式显示自己的说明，不要求重新输入英文拼写。成绩记录原作答，不会因为复习而改写。

## 本次打磨

页面在当前浏览器记住上次选择的听写方向。中文作答说明缩为一行，反馈明确区分「回答正确」「未匹配」和「已查看答案」，标明参考释义；成绩中正确和错误答案使用不同颜色。

手机上的中文作答界面收紧播放器和按钮间距，长英文单词、释义和答案可换行。检查后焦点进入下一词按钮，进入下一词时回到输入框，完成练习后移到成绩标题；中文输入法确认候选时的 Enter 不提交，正在输入时点击「查看答案」仍可继续。持续按住 Enter 不跳过反馈。

## 保存和构建

第四版位于独立的 `v4/`。根目录原版、`v2/`、`v3/` 及其源码保持原内容。上传包仅添加各新版文件，包含所需的旧版附加文件，避免覆盖根目录旧版页面。

运行 `python tools/build_v4.py`，仅使用 Python 标准库。构建器先核对原版 Git blob SHA，然后依次应用第三版和第四版补丁；每个接入点必须恰好匹配一次，失败就停止。释义判分与界面辅助函数嵌入原应用的 React 作用域，不改动词库存储或同步协议。输出目录强制为项目根下 `v4/`，拒绝覆盖旧版。

离线缓存按版本、目录和内容隔离，保留旧版缓存，不主动激活更新或刷新正在练习的页面。原版自己的缓存清理逻辑可能删除新版缓存，正式离线前应联网打开第四版，再在没有开始练习时断网刷新确认。草稿纸只在当前会话内存中存在，刷新、退出或关闭会清空，需要保留请逐页导出 PNG。
