# 听写本第六版使用与上传说明

第六版改进键盘听写的错词重写、中文判分和发音恢复。第五版与更早版本保留原内容。此交付是本地网页与上传包，尚未替你发布到 GitHub Pages。

## 错哪项，重写哪项

首页选择「键盘听写」，勾选「答错后再写一遍」，再开始练习。四种听写方向共用这个开关，并记住你的选择。

- 听英文写英文、听中文写英文：拼写错后重写英文。
- 听英文写中文：意思错后重写一种完整中文意思。
- 听英文写英文和中文：只重写答错的部分；两项都错则两项都要重写，可以分次确认，已写对的一项会保留。
- 点「不会，查看答案」后，重写当前模式要求的全部内容。

重写正确后才能进入下一词；最后一词也一样。重写仅用于巩固，成绩保留第一次作答的结果，错词仍可在结束后集中练习。关闭首页开关后，可以照常看完答案直接继续。

纸笔听写仍由你自行核对答案，保留 iPad 草稿纸，不要求键盘重写，也不会识别手写内容。草稿只在本轮页面中保留，需要留存时请先保存图片。

## 中文「的／地」兼容

首次作答与错词重写均不区分「的」和「地」，例如词库是「拼命地」，写「拼命的」也正确；词库是「小心地处理事情」，写「小心的处理事情」也正确。「得」不在本次兼容范围内。

中文依然按词库登记的完整意思核对，任意答出一种即可。例如 `bank 银行；河岸`，答「银行」或「河岸」均正确。不要求输入词性、编号等格式。只写意思的一部分不算正确；一次写多种时，各种意思都需要匹配。

程序不会自动推测未登记的同义词。如果你希望「好处」和「益处」都能答，请在词库中写成「益处；好处」。

## 无声或一直加载时

首页仍可选择设备语音、美式词典录音、英式词典录音；在线资源仍是 Free Dictionary API，没有新增需要账户或付费密钥的服务。

1. 先用首页的试听确认设备能发声。
2. 在线查询或录音起播超过约 5 秒，会结束等待并尝试设备英语发音。设备语音没有启动反馈时，也会在约 5 秒后显示失败，避免一直停在准备状态。
3. 如果浏览器要求手动点按，键盘听写会出现「点击播放在线录音」。此时直接重用已经查到的录音信息，避免再次查询后失去播放时机。
4. 在线查询卡住或播放失败时，可点「用设备语音播放」。切换后，之前迟到的在线请求不会突然开始发声。
5. 网络恢复后，可以点「重试在线录音」。

纸笔模式发生播放阻止或最终失败时会暂停，不把无声失败当成播放完成，也不跳过单词。使用纸笔界面的「继续」或「重听」重试即可。若始终无声，返回首页改为设备语音，并检查设备音量、输出设备及系统语音可用情况。

查询在线录音只发送当前英文单词，不发送你的答案、中文释义或整份词库。录音不覆盖所有单词、短语和口音，也不是可下载的整套离线音频包。原有来源与授权展示继续保留。

本次自动化检查用模拟网络与语音验证超时、播放阻止、迟到响应及恢复流程。没有完成真实在线录音试听，也没有在实体 iPad 上验证系统语音和 Apple Pencil；不能据此保证你所在网络或设备的声音一定可用。

## 在电脑与 iPad 上打开

本地体验使用「听写本-v6-中英文错词重写.html」。该文件不是公网网址，电脑的本地路径不能直接作为 iPad 的在线地址。

要让 iPad 访问，请把上传包解压后上传到原 GitHub 仓库，保留文件夹层级。第六版网页入口在 `v6/index.html`。已有 GitHub Pages 配置若从仓库根目录发布，部署成功后可使用：

`https://hongcheng20071024-maker.github.io/tingxieben/v6/`

上面是部署后的预期网址，目前未验证已上线。不要把 ZIP 文件本身当网页上传，也不要用第六版 HTML 覆盖原版根目录的 `index.html`。本包同时携带前几版的追加文件，方便保留已有版本；原入口与旧版本文件不会因本地打包而被改写。

用 iPad 的 Safari 打开部署后的网址，试听确认可用后，可从分享菜单添加到主屏幕。如果已经添加过第五版，请为 `/v6/` 页面另建入口，旧图标不会自动变成第六版。

词库保存在当前浏览器。相同网站地址下的旧版和第六版沿用相同存储，通常能继续读取已有词库；换设备、换域名，或从本地文件迁到网页时，应先在旧设备「导出词库」，再在新页面「导入词库」。本次没有新增自动云同步。
