# 听写本 · 英语单词听默写

按课本单元组织自己的英语词库，用键盘听写或纸笔听写。单文件网页应用，已做成可安装的 PWA。

**在线地址：** https://hongcheng20071024-maker.github.io/tingxieben/

## 在 iPad / iPhone 上安装

1. 用 **Safari** 打开上面的地址（必须是 Safari，不能是微信内置浏览器）。
2. 点底部/顶部的 **分享** 按钮 → **添加到主屏幕**。
3. 主屏幕出现「听写本」图标，点开即全屏使用。

首次打开联网，之后离线也能用（Service Worker 已缓存整站）。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `index.html` | 应用本体（由原始单文件 HTML 注入 PWA 配置生成） |
| `manifest.webmanifest` | PWA 清单：名称、图标、全屏模式 |
| `sw.js` | 离线缓存（cache-first） |
| `icon-*.png` | 主屏幕图标（180 / 192 / 512 / maskable） |
| `library-backup-unit1.json` | 词库备份（大学英语 Unit1，27 词），可在应用内「导入词库」 |

## 词库与数据

- 词库保存在**各设备自己的浏览器**里，不跨设备自动同步。
- 换设备：旧设备「导出词库」→ 新设备「导入词库」。
- 页面首次打开时会自动预置 `大学英语Unit1`（27 词），仅当浏览器里还没有任何词库时写入。
- 不要在无痕模式长期保存；清理浏览器数据前先导出备份。

## 发音

朗读使用系统的语音包（Web Speech API）。若没有声音，检查：

- iPad：**设置 → 辅助功能 → 朗读内容 → 声音 → 英语**，下载一个英语语音包。
- 页面里「更多声音与语音包」有官方指引入口。
