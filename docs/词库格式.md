# 词库格式

听写本的词库就是一份 JSON 文件。你可以自己写、用脚本生成、或让 AI 批量生成后直接导入。

## 一、导出 / 导入文件格式

应用内「导出词库」得到的文件长这样：

```json
{
  "format": "listen-write-v1",
  "exportedAt": "2026-10-09T11:28:22.464Z",
  "groups": [
    {
      "name": "大学英语Unit1",
      "words": [
        { "word": "desperately", "meaning": "拼命地;不顾一切地" },
        { "word": "require",     "meaning": "需要;有赖于" }
      ]
    }
  ]
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `format` | string | 固定 `listen-write-v1` |
| `exportedAt` | string | 导出时间（ISO 8601），导入时会忽略 |
| `groups` | array | 单元（分组）列表，可以有任意多个 |
| `groups[].name` | string | 单元名，显示在应用首页 |
| `groups[].words` | array | 该单元的单词 |
| `words[].word` | string | 英文单词 / 短语 |
| `words[].meaning` | string | 中文释义；多个义项用**英文分号 `;`** 分隔 |

**导入**：应用里选「导入词库」→ 选这个 JSON 文件即可，可一次导入多个单元。

## 二、浏览器内部存储格式

词库实际存在浏览器 localStorage 的 `listen-write-library-v1` 里，是一个**数组**（比导出文件少一层包装，多两个字段）：

```json
[
  {
    "id": "a1b2c3d4-0000-4000-8000-000000000001",
    "name": "大学英语Unit1",
    "words": [{ "word": "require", "meaning": "需要;有赖于" }],
    "revision": 1
  }
]
```

- `id`：分组唯一标识，用 UUID 字符串。预置的「大学英语Unit1」固定用 `a1b2c3d4-0000-4000-8000-000000000001`。
- `revision`：分组修订号，应用自己维护，手写时给 `1` 即可。

> 想直接改浏览器里的数据（高级操作）：打开应用页面 → 开发者工具 → Application → Local Storage → `listen-write-library-v1`。改坏了就把导出的 JSON 重新导入。

## 三、用 AI 批量生成词库（提示词模板）

把下面这段直接复制给 ChatGPT / Claude / 豆包等，只改括号里的内容：

```text
请帮我生成一份英语单词听写本用的词库 JSON。要求：
1. 只输出 JSON，不要任何解释文字，不要 markdown 代码块标记。
2. 严格按这个结构：
{"format":"listen-write-v1","exportedAt":"2026-01-01T00:00:00.000Z","groups":[{"name":"单元名","words":[{"word":"英文单词","meaning":"中文释义"}]}]}
3. 我需要这些单元：（例如：人教版高中英语必修一 Unit1 / Unit2）
4. 每个单元的词表：（把课本词汇表逐行贴在这里，或写"按课本词汇表"，共 N 个词）
5. 释义用中文，多个义项之间用英文分号 ; 分隔。
6. 单词保持小写原形；词组也照写（如 take part in）。
```

拿到 JSON 后存成 `.json` 文件（UTF-8 编码），在应用里「导入词库」即可。

## 四、注意事项

- 文件必须是 **UTF-8** 编码，否则中文释义会乱码。
- 字段名区分大小写：`word` / `meaning` / `groups` / `name`。
- 释义里的多义项请用英文分号 `;`，不要用中文分号 `；`（显示时按英文分号切分）。
- 单元名会直接作为首页标题显示，建议带上来源，例如 `必修一 Unit3`。
- 只想手工加几个词，直接在应用里编辑更快，不必写文件。
