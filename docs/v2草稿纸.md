## 使用

在 iPad 的 Safari 中进入 v2，选择词库并开始「纸笔听写」，会显示草稿纸。可以用手指或 Apple Pencil 写字，也可以切换「写字」「橡皮」、撤销、重做、清空和分页。选择「仅手写笔」后，手指触摸不会落笔，方便用 Apple Pencil 时避免手掌误触。电脑可以使用鼠标。

草稿区有紧凑播放栏，能查看当前词进度并操作开始、暂停、继续和重听。它与原有播放按钮同步，竖屏书写时可直接在草稿附近控制听写，核对本轮答案后自动禁用播放。

切换单词、暂停播放、核对本轮答案时，草稿会继续保留。离开本轮或重新开始时清除。草稿仅在本轮页面的内存中临时保存，不会上传到词库，也不会在线同步，刷新后无法恢复。关闭、刷新页面前，请使用「保存本页图片」导出当前页 PNG；多页草稿需要逐页保存。iPad 上可在 Safari 下载中打开，再保存到「照片」或「文件」。

在同一浏览器、同一站点下，原版与 v2 沿用本地词库。切换版本前建议先导出词库备份。不同设备之间，以及 Safari 与添加到主屏幕的应用之间，词库不保证自动共享，请使用原有的导入、导出功能。新版上线后，请从 v2 地址重新添加到主屏幕，方便打开新版；这不会改变旧主屏幕入口。

## 构建与恢复

在仓库根目录运行：

```text
python tools/build_v2.py
```

构建工具先调用原有 `tools/build_site.py`，再把 `source/scratchpad.css` 和 `source/scratchpad.js` 内联到 `v2/index.html`。它只写入 `v2/`，不改动根目录的原版应用、原始 HTML、原版 Service Worker 或词库备份。新版图标与应用清单也放在 `v2/`。同一份源码重复构建结果一致。

新版离线缓存使用内容哈希区分版本，缓存清理仅作用于自己的目录。导航时先取最新页面，网络不可用时使用已缓存的页面。新 Service Worker 等旧页面关闭后生效，不会在正在听写时强制刷新。首次打开需联网；离线发音仍取决于设备提供的语音，在线词典录音仍需联网。

原版的 Service Worker 保持原样，其首次激活或以后更新时仍可能清理新版缓存。首次上线建议先联网打开原版，再联网打开 v2。以后首次返回原版或原版更新后，请联网重开 v2。新版会在成功联网导航后自动补齐自己缺失的离线资源，避免覆盖最新页面，也不会每次重复下载已存在的资源。补齐在后台运行，页面加载完成本身不表示缓存已经完成；正式离线使用前，请在尚未开始听写时断网刷新一次，确认新版仍能打开。刷新会清空本轮草稿，请在开始听写前验证。补齐失败不会阻止正常打开网页，但此时不能保证全部离线资源可用。

本次构建的离线缓存内容标识为 `d422b70dfee7430682c5`。

需要恢复时直接打开原版地址。若需撤掉试用版，只撤回新增的 `v2/`、草稿纸源码、新构建脚本和本说明即可；原版无需重建。原版 ZIP 备份另行提供，保留其完整文件即可重新上传恢复。

离线缓存行为可在构建后运行 `node tests/v2-worker.test.cjs` 验证，不需要额外安装测试依赖。
