# 第五版发音资源说明

第五版把在线词典录音升级为可选的听写主音源。在首页的“发音资源”中可以选择设备语音、美式词典录音或英式词典录音，再点击“试听发音资源”。默认仍为设备语音。选择在线资源后，练习中的播放、重听、慢速听和错词英文播放都使用所选资源；中文播报使用原来的设备中文声音。

## 已接入的资源与使用方式

| 资源 | 第五版状态 | 适用情况与限制 |
| --- | --- | --- |
| 设备系统语音 | 已接入，默认选项 | 可选择设备提供的音色。不同设备的声音和是否需要联网可能不同。 |
| Free Dictionary API 的美式、英式录音 | 已接入，作为可选主音源 | 按当前英文单词查询，优先播放有来源和许可信息的录音；不保证每个课本单词或短语都有录音。 |
| Wikimedia Commons / Lingua Libre | 已研究，未另外接入或打包 | 官方提供发音库及数据集下载说明，适合将来制作与个人课本单词匹配的录音包。需要逐词核对单词、口音和文件授权；数据集教程有历史说明，不能据此保证整包下载现在可用。 |
| Microsoft Azure Speech | 已研究，未接入 | 官方提供神经语音和音色列表接口，需要 Azure 账户、Speech 资源以及密钥或令牌。适合以后增加跨设备一致的合成音色。 |
| Google Cloud Text-to-Speech | 已研究，未接入 | 官方合成接口接收文本、音色和音频设置，要求身份授权。需要服务端保存凭据，再向网页返回音频。 |

Free Dictionary API 官方说明提供按单词查询的公开接口，并在 `phonetics[].audio` 中返回录音地址。[官方接口说明](https://dictionaryapi.dev/)、[官方代码仓库](https://github.com/meetDeveloper/freeDictionaryAPI)。

Commons / Lingua Libre 的下载说明介绍按语言、分类或录音者获取素材，并明确音频文件遵循各自文件说明页的授权。页面中的部分下载状态说明来自较早年份，因此本版没有直接把它作为可用的离线资源包交付。[官方数据集说明](https://commons.wikimedia.org/wiki/Help:Lingua_Libre/Download_datasets)。

Azure 的 REST 文档说明神经语音支持、资源创建与请求授权；Google 的合成文档说明请求格式及 OAuth 授权要求。它们属于后续可选的服务端方案，本版没有放入密钥，也没有调用未经公开文档支持的接口。[Azure 官方接口文档](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/rest-text-to-speech)、[Google 官方合成接口](https://docs.cloud.google.com/text-to-speech/docs/reference/rest/v1/text/synthesize)。

## 播放与回退

- 所选词典资源决定英文录音口音。找不到对应的美式或英式录音时，显示原因并改用设备英语发音，不把其他口音标为所选口音。
- 查词或录音启动超过 6 秒、播放失败或录音迟迟不结束时，改用设备语音。系统会清理旧录音，避免录音与设备声音重叠。
- 重新播放、切换单词、退出练习或页面进入后台都会取消旧播放及未完成的查询。迟到的网络结果不能播放旧单词或触发下一题。
- 慢速播放设置音频速率，并启用浏览器支持的音高保持设置；效果需在实际设备上试听。
- 查询结果只在当前页面内存中缓存，最多 120 个单词。不批量下载整份词库、不把录音或词库写入在线服务。

在线选择的口音优先于首页的设备口音选项。设备音色用于设备播放；自动回退会根据所选美式或英式资源寻找英语系统声音。如果设备没有合适的英语声音，继续使用原有错误提示与重听操作。

## 查询内容与录音来源

网络查询只发送正在播放的英文单词。中文释义、用户答案、分组和整份词库不会作为查询内容发送。请求不携带浏览器凭据，页面地址不作为查词请求的来源信息发送。第三方服务仍会接收到完成网络请求所需的连接信息。

本版只接受单词完全匹配、音频位于 `api.dictionaryapi.dev` 的指定发音目录、来源页为 Wikimedia Commons、并且带有 Creative Commons 许可信息的资源。不能确认口音或授权信息的资源会回退至设备语音。官方首页的旧例子包含其他域名的音频，本版不会自动放宽来源规则来播放它。

键盘听写提交答案后可查看本词的“录音来源与作者”和许可链接。纸笔听写结束后，“发音来源与授权”列出本轮实际播放的所有录音，重复播放只列一次。答题前不显示含单词的录音链接，以免泄露答案。停止播放后保留必要的来源信息，新单词开始播放时清除上一词的当前记录。

## iPad 与验证范围

在 iPad 浏览器中，先点击“试听发音资源”或“开始听写”，听不到时点击“重听”。本版处理媒体播放被浏览器拒绝的情况并回退，但真实 Safari 的播放许可、设备音色、网络质量和声音效果仍需在自己的 iPad 上检查。

自动化检查：`tests/audio-v5.test.cjs` 使用模拟网络、设备语音和音频对象，22 项检查通过。覆盖选项存储、精确单词与口音、可信资源、中文继续使用设备音色、慢速、断网与超时回退、迟到结果、重复播放、取消、答题前隐藏链接、答题后保留授权、纸笔整轮授权列表及缓存限制。

本次已尝试查询 `hello`、`apple`、`benefit` 的真实接口。网页读取工具无法获取结果；获得临时联网权限后，Python 请求仍收到 HTTP 403，PowerShell 请求遇到当前运行环境的 SSL 身份验证错误。因此未确认这三个词目前的录音数量，未完成真实网络录音试听，也没有把浏览器模拟测试当作 iPad 实机验证。这是本次测试环境的结果，不代表接口在你的设备上一定不可用。

## 开发接口

`v5UseSpeech(source)` 保持原 `bg()` 的 `speak(text, language, rate, onEnd, onError, voice)`、`cancel()`、`clearError()` 以及音色与错误字段，另提供 `loading`、`notice`、`recording`、`recordingsUsed` 和 `sourceLabel`。

首页使用 `V5AudioSetting({source, onChange, onPreview})`，已知示例词的试听状态可显示来源；练习使用 `V5AudioStatus({speech, showCredits})`，只有答案已显示时才启用 `showCredits`。纸笔完成页面使用 `V5AudioCredits({speech})`，不要在题目隐藏时渲染它。

偏好由 `v5ReadAudioPreference()` / `v5SaveAudioPreference(value)` 读取保存。存储键为 `listen-write-audio-source-v5`，值是 `device`、`dictionary-us`、`dictionary-uk` 之一的普通字符串。存储不可用时仍能使用当前选择。
