# 听写本 v6.1 使用与上传说明

这一版按交接档案完成第一批体验优化。第六版及更早版本保留，可继续打开旧入口。此交付为本地网页和上传包，尚未发布。

## 三处改变

1. 重写两项时，在英文输入框按 Enter 先跳到中文输入框，不提前判中文错误。最后一个待完成输入框按 Enter，或点「确认重写」，才检查答案。通过的项目仍会锁定保留；首次作答的成绩不变。
2. 首页显示本轮所选分组、总词数、方向、重写开关和发音来源。电脑开始按钮放在设置上方，手机底部固定显示开始入口。语速、发音来源、纸笔间隔等放进「更多设置」，音色位于其中的「更多发音设置」。分组多时可以在列表内滚动或展开列表。
3. 答错后的参考答案、英文发音和重写输入放在同一区域。宽屏并排显示，手机上下排列。原答案收进「查看本次作答」，展开后仍可查看首次答案和加载词典录音。下一词不可用时会说明需先完成重写。

四种键盘方向、纸笔听写、草稿纸、导入导出和原词库规则仍可使用。「答错后再写一遍」由首页开关控制；双项听写只重写错项。中文仍需命中词库中的一种完整意思，「的／地」兼容，「得」未并入。查看答案后仍按原规则重写，纸笔不要求键盘输入。

选中的词缺少所需中文释义时，本轮仍会阻止开始并说明原因，不会自动删掉这些词。可以编辑分组补全，或选择不需要中文释义的听写方向。

## 打开与上传

电脑本地体验可直接打开「听写本-v6.1-体验优化.html」。本地文件路径不是 iPad 可以直接访问的在线网址。

上传包解压后，按原文件夹层级上传到原 GitHub 仓库。新版本入口为 `v6-1/index.html`；保留原根目录 `index.html` 和 `v6/`。不要只上传 ZIP，也不要将新 HTML 改名后覆盖旧入口。包中含前几版的追加文件；仓库已有同名文件时先比较内容，如果你曾在线修改过它们，应保留那些修改，仅添加本批新增文件。

GitHub Pages 若从仓库根目录发布，部署完成后的预期地址为：

`https://hongcheng20071024-maker.github.io/tingxieben/v6-1/`

以上地址尚未核实上线。部署后在 iPad／iPhone 的 Safari 打开，再按需要添加到主屏幕。旧主屏幕入口不会自动改为 v6.1。

词库继续保存在浏览器，沿用原 `listen-write-library-v1` 存储键。同一网站来源通常可读取旧版词库；本地文件、不同域名和不同设备之间不保证共享。迁移前先在旧版导出词库，再到新页面导入。本批未增加云同步、长期错词本、刷新恢复或草稿持久化；离开草稿轮次前仍应保存图片。

## 验证范围与备份

自动检查覆盖中文判分、组合判分、重写流程、原音频恢复机制和新版离线缓存；浏览器报告另列首页、键盘、纸笔和响应式布局场景。测试网络与语音由模拟事件控制，用于验证交互，不代表真实设备已经听到声音。

实体 iPad、Apple Pencil、系统软键盘及真实在线录音未完成验证。在线录音仍沿用第六版来源及回退机制，没有接入新服务。

原第六版完整备份位于 `outputs/backups/v6-before-v6-1-2026-10-14/`，包含可编辑源码、交付网页、上传包、说明及校验清单。新版独立开发目录为 `work/tingxieben-v6-1-development/`，构建入口为 `tools/build_v6_1.py`，输出限定为 `v6-1/`，缓存命名空间也独立。无需删除新版即可回到旧版；共享词库的编辑不会随程序版本回退而撤销。
