# 听写本第五版：听英文，写英文和中文

第五版增加「英文发音 → 写英文和中文」。播放一个英文单词，分别填写英文拼写和任意一种完整中文意思。两项都正确才算这一词正确；成绩页也分别显示拼写和意思的正确数量。旧版听写方向和 iPad 草稿纸继续保留。

## 开始练习

1. 在首页选择自己的课本分组和「键盘听写」。
2. 把「朗读内容」切换为「英文发音 → 写英文和中文」。
3. 选择「发音资源」，点击「试听发音资源」确认声音后开始听写。
4. 听英文，填好两个输入框，点击「检查英文和中文」。输入英文后按 Enter 可转到中文框；中文框按 Enter 提交。中文输入法选字时的 Enter 不会直接判分。

例如词库是 `bank 银行；河岸`：英文写 `bank`，中文写「银行」或「河岸」均可。中文只写一种即可；若一次写多种，每一种都须匹配词库。中文判分沿用第四版规则：按词库登记的完整释义匹配，整理词性、编号、空格及常见标点，不需要写 `n.`、`v.` 等。它不会推测未录入的同义词，也不接受只写释义的一部分。想同时接受「益处」和「好处」，请在词库写成 `益处；好处`。

提交后分别显示英文和中文是否正确，并保留你的两份答案。查看答案按本词未答对记录。成绩以第一次作答为准，重新播放或重写不会改变首答成绩。结束后仍可只练错词。

## 答错后再写一遍

首页可以开启或关闭「答错后再写一遍」。在双输入模式中，英文拼写错误或查看答案后，重新拼写正确才能继续；只有中文意思错误时可以直接进入下一词。重写是巩固练习，第一次错误仍保留在成绩中。

选择「纸笔听写」也可使用双项模式：在纸上或 iPad 草稿纸写英文和中文，结束后自行核对。程序不识别手写内容，重写开关用于键盘听写。退出、刷新或关闭页面会清空本轮草稿，需要保留时先逐页保存 PNG。

## 发音资源

首页新增三种选择：设备语音（默认）、美式词典录音、英式词典录音。在线录音取自 [Free Dictionary API](https://dictionaryapi.dev/)，查询只发送当前正在播放的英文单词，不发送中文意思、答案或整份词库。

查不到所选口音、来源或许可不能确认、断网、超时或播放失败时，会说明原因并改用设备发音。中文播报仍使用设备中文声音。录音并非覆盖所有课本单词和短语，也没有下载整套离线音频包。提交答案后可查看本词录音来源；纸笔听写结束后可查看本轮实际播放录音的来源列表。

本次研究了 Commons / Lingua Libre 的发音素材，以及 Azure 和 Google 的合成语音服务。后两者需要账户、凭据和服务端，本版未接入。已接入的资源、来源规则和许可信息见包内 `docs/v5音频资源.md`。

真实接口在当前测试环境返回 HTTP 403 或 SSL 错误，未完成真实录音试听。请在自己的 iPad 上先试听；不能播放时仍可使用设备语音。不同设备的系统音色会有所不同。

4. 检查 `v5/` 下有网页、worker、manifest 和四个图标，共 7 个文件，然后合并到 GitHub Pages 的发布分支。
5. Pages 发布完成后，在 Safari 打开 [第五版地址](https://hongcheng20071024-maker.github.io/tingxieben/v5/)，可通过 Safari 的分享菜单添加到主屏幕。

第五版沿用原词库存储方式。在同一网站、同一浏览器打开时可沿用词库；不同设备、浏览器、网站或主屏幕应用之间可能需要导入词库备份。本次未新增跨设备同步服务。本地 HTML 也不能代替已发布的网址。

正式离线前，先联网打开第五版，再在未开始练习时断网刷新确认。离线可使用已缓存网页和设备提供的语音；词典在线录音需要网络。
